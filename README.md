# LeadIQ AI

LeadIQ AI is an intelligent lead qualification dashboard that scores real-estate prospects, identifies purchase intent, and recommends the right sales action.

## Features

- Real-time lead scoring from budget, timeline, and acquisition source
- Hot, Warm, and Cold qualification categories
- Searchable lead intelligence table
- New-lead analysis form with immediate scoring
- Detailed AI recommendation drawer
- Realistic pipeline metrics and intent signals
- Responsive desktop and mobile interface

## Demo behavior

This first portfolio version runs without an external AI token. Its transparent scoring model makes the demo reliable and testable. A later production phase can replace the local scoring function with an AI API and connect results to GoHighLevel through webhooks.
